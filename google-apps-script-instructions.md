# Установка google-apps-script.gs

Скрипт принимает POST-запросы от формы заявки на сайте (`leadForm` в `index.html`) и дописывает
каждую заявку строкой в лист «Заявки» Google-таблицы. ИМТ и степень считаются на сервере из
роста/веса — значения от клиента игнорируются намеренно (эндпоинт публичный, без авторизации).

## Шаги

1. Создай Google-таблицу — sheets.new.
2. В таблице: **Расширения → Apps Script**.
3. Удали код-заглушку в редакторе, вставь содержимое `google-apps-script.gs` целиком.
4. Сохрани (Ctrl+S).
5. **Деплой → Новое развёртывание** (Deploy → New deployment):
   - Тип: **Веб-приложение** (Web app)
   - Execute as: **Me**
   - Who has access: **Anyone** — обязательно, иначе сайт не сможет отправлять заявки без входа в Google
   - Deploy → разреши доступ (это твой скрипт к твоей же таблице).
6. Скопируй выданный **URL веб-приложения** (заканчивается на `/exec`).
7. В `index.html` найди `const LEAD_WEBHOOK_URL = '...'` и вставь туда этот URL.

## После изменений в коде скрипта

Правка кода в редакторе Apps Script не применяется к уже выданному URL автоматически.
Нужно: **Deploy → Manage deployments → Edit (карандаш) → Version: New version → Deploy**.
Сам URL при этом не меняется.

## Что писать в таблицу

Колонки листа «Заявки»: Дата, Имя, Телефон, Возраст, Рост, Вес, ИМТ, Степень, Город, Источник.
Порядок задан массивом `FIELDS` в начале `google-apps-script.gs` — при добавлении нового поля
формы правь только его, шапка и строка данных собираются из него автоматически.
